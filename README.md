## 作品簡介（Project Overview）

現代人養寵物越來越多,已形成一種新型的社會趨勢。傳統在養寵物上都是仰賴主人自身學習照顧指南或者過去養殖經驗,而我們認為若能結合當前正開始蓬勃發展之 AI技術與已經相對成熟的物聯網設備,開發出一套居家智慧寵物照顧系統,不只能夠帶來更方便的寵物養殖照顧模式、遠程互動讓寵物不孤單,還能夠做到更健康、更安全的寵物照顧。

---

## 作品目標（Project Purpose）

* 減少寵物醫療成本、流浪動物治理成本
* 擴大可以用在農場、動物園等場域
* 對經濟動物、觀賞動物等能提供智慧化照顧
* 幫助稀有動物、保育動物、瀕危生物之復育

---

## 作品功能（Key Features）

我們提出的居家智慧寵物照顧系統可以達到

* 協助新手照顧寵物、減低學習時間成本。
* 實現精準照顧,了解寵物活動、睡眠、飲食狀況。
* 及早檢測健康下滑徵狀,例如睡眠不正常、活動力下降等,以警示主人應就醫檢查。
* 避免寵物走失,在意外離開家門或貓咪爬出窗外等狀況時提出警示。

## 使用技術（Technologies Used）

​* 前端介面開發：Python、Tkinter  
​* 電腦視覺與深度學習：Ultralytics YOLO11（搭配 Fine-tune 微調腳本與訓練資料集）、Webcam 影像輸入  
​* 生成式 AI 與語言模型：ChatGPT（經由 API 串接與 Prompt 提示詞工程）  
​* 硬體控制與感測器：Arduino Nano 微控制器、溫度計、濕度計  
​* 無線通訊技術：藍牙傳輸（Bluetooth）

## 作品流程（How the Project Works）

1. 打開作品，開啟鏡頭拍攝寵物，同時arduino會把溫濕度感應偵測模組的資料實時透過藍芽傳到前端

2. 透過現成的YOLO模型識別寵物種類、活動量以及休息量

3. 按下AI分析按鈕後，溫濕度資料以及寵物資訊會變成指令透過API傳送至AI進行分析，並在分析完成後回傳
